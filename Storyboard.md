## Scene 3 — Visual Intuition (~35s)

**Visual:**
- 3D axes with animated camera rotation

**Narration:**

## Scene 4 — Complete Worked Example (~90s)

**Visual:**
- Original equations → augmented matrix
- **Step 1:** R₂ ← R₂ − 2R₁ with arithmetic shown
- **Step 2:** R₃ ← R₃ − R₁ with arithmetic shown
- **Step 3:** R₃ ← R₃ − R₂ with arithmetic shown
- Final REF matrix with yellow pivot highlights
- REF vs RREF distinction noted
- Back substitution: z = 3, y = 2, x = 1

**Narration:**
> Now the full worked example... [walks through each step with arithmetic]... Back substitution: 3z = 9, so z = 3. y − 3 = −1, so y = 2. x + 2 + 3 = 6, so x = 1.

## Scene 5 — Interpretation and Verification (~40s)

**Visual:**
- Solution (1, 2, 3) in a green box
- Substitution into each original equation with green ✓
- Special case: [0 0 0 | 5] → no solution
- Special case: [0 0 0 | 0] → dependent, possibly infinite solutions

**Narration:**
> Our solution is x = 1, y = 2, z = 3. Verifying... If we obtained a row [0 0 0 5], the system is inconsistent. A row of all zeros indicates a dependent equation.
